# 🖨️ Linux Print Studio

> **Professional PDF & Image Printing Suite for Linux**  
> লিনাক্সে প্রিন্টিংয়ের যাবতীয় ঝামেলা দূর করার জন্য একটি পরিপূর্ণ ও সহজ প্রিন্টিং সফটওয়্যার।

---

## 🎯 এটি কেন তৈরি করা হয়েছে? (Why Linux Print Studio?)

লিনাক্সের ডিফল্ট প্রিন্টিং ডায়ালগে (CUPS / GTK Print Dialog) অনেক সাধারণ ফিচার ঠিকমতো কাজ করে না বা অপশনগুলো লুকানো থাকে:
1. **রিভার্স পেজ প্রিন্ট (Reverse Order):** প্রিন্টারের ট্রেতে পেজ উল্টো জমা হলে ফাইল পেছনের পাতা থেকে প্রিন্ট করা প্রয়োজন হয়, যা ডিফল্ট উইন্ডোতে সহজে পাওয়া যায় না।
2. **বিজোড়/জোড় পেজ (Odd / Even Pages):** ডুপ্লেক্স বা ম্যানুয়াল দুই পিঠে প্রিন্ট করার জন্য বিজোড় এবং জোড় পাতার নিখুঁত ফিল্টারিং।
3. **ডেডিকেটেড সাদা-কালো (Force True Black & White):** পপআপ উইন্ডো বা ড্রাইভারের ডিফল্ট কালার থাকলেও ডকুমেন্ট যাতে **১০০% গ্রেস্কেল/সাদা-কালো** তে প্রিন্ট হয় (যাতে কোনো রঙিন কালি বা টোনার নষ্ট না হয়)।
4. **বিল্ট-ইন লাইভ প্রিভিউ (Live Preview):** প্রিন্ট করার আগেই পিডিএফ এবং ছবি উইন্ডোতে দেখা এবং পেজ উল্টানো।

## ✨ প্রধান ফিচারসমূহ (Key Features)

| ফিচার | বিবরণ |
| :--- | :--- |
| 📄 **PDF ও ছবি সাপোর্ট** | যেকোনো PDF ফাইল এবং ইমেজ (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`, `.tiff`) সরাসরি ওপেন করা যায়। |
| 🔄 **Reverse Order (পিছন থেকে সামনে)** | মাত্র ১-ক্লিকে শেষ পাতা থেকে প্রথম পাতা ক্রমে প্রিন্ট করার সুবিধা। |
| 📑 **Page Selection** | **All Pages**, **Odd Pages Only (১, ৩, ৫)**, **Even Pages Only (২, ৪, ৬)** এবং **Custom Range (যেমন: ১-৩, ৫, ৮-১০)**। |
| 🔘 **True B&W / Grayscale Conversion** | সফটওয়্যার লেভেলে ডকুমেন্টকে ১০০% গ্রেস্কেলে কনভার্ট করে প্রিন্টারে পাঠানো হয়। প্রিন্টার বা পপআপে কালার সিলেক্ট থাকলেও এটি কেবল সাদা-কালোতেই প্রিন্ট করবে! |
| ⬛ **Pure Monochrome (High-Contrast)** | টেক্সট ডকুমেন্ট ও ফটোকপির জন্য চরম টোনার সাশ্রয়ী পিওর ১-বিট ব্ল্যাক অ্যান্ড হোয়াইট মোড। |
| 🔍 **Interactive Live Preview** | পেজ নেভিগেশন (First, Prev, Next, Last), জুম ইন/আউট, Fit to Page, Fit to Width এবং মাউস হুইল জুম। |
| 🖨️ **1-Click CUPS Direct Print** | কোনো বিরক্তিকর জটিল পপআপ ছাড়াই লিনাক্সের প্রিন্টারগুলোতে সরাসরি এক ক্লিকে প্রিন্ট জব পাঠানো। |
| 💾 **Export Processed PDF** | পেজ সাজানো, রিভার্স ও গ্রেস্কেল করা ফাইলটি নতুন PDF হিসেবে সেভ করে রাখার সুবিধা। |
| 🖱️ **Drag & Drop** | ফাইল ড্র্যাগ করে সফটওয়্যারের ভেতর ছেড়ে দিলেই সাথে সাথে ওপেন ও প্রিভিউ হবে। |

## 🚀 ইন্সটলেশন ও ব্যবহার (Installation & Usage)

### ১. এক ক্লিকে অটোমেটিক ইন্সটল (Ubuntu, Debian, Mint, Fedora, Arch):

টার্মিনাল ওপেন করে প্রজেক্ট ফোল্ডারে রান করুন:

```bash
chmod +x install.sh
./install.sh
```

এটি স্বয়ংক্রিয়ভাবে প্রয়োজনীয় লাইব্রেরি ইনস্টল করবে, অ্যাপ্লিকেশন মেনুতে আইকন যোগ করবে এবং রাইট-ক্লিক "Open With" অপশন সক্রিয় করবে।

---

### ২. সরাসরি রান করা (Without Installing):

আপনার মেশিনে ডিপেন্ডেন্সি ইনস্টল থাকলে সরাসরি রান করতে পারেন:

```bash
# Ubuntu / Debian / Linux Mint:
sudo apt install python3-pyqt6 python3-pil cups-client
pip install PyMuPDF

# Arch Linux / Manjaro:
sudo pacman -S python-pyqt6 python-pymupdf python-pillow cups

# Fedora:
sudo dnf install python3-pyqt6 python3-pillow cups
pip install PyMuPDF
```

অ্যাপ্লিকেশনটি রান করতে:
```bash
python3 linux_print_studio/main.py
```

অথবা যেকোনো পিডিএফ/ইমেজ দিয়ে ওপেন করতে:
```bash
python3 linux_print_studio/main.py /path/to/document.pdf
```

## 🖥️ কীভাবে ব্যবহার করবেন? (Step-by-Step Guide)

1. **ফাইল ওপেন করুন:**
   - `Open PDF / Image...` বাটনে ক্লিক করুন অথবা ফাইলটি ড্র্যাগ করে প্রিভিউ উইন্ডোতে টেনে আনুন।
2. **কালার মোড নির্বাচন করুন:**
   - **Original / Full Color:** মূল রঙিন ডকুমেন্ট।
   - **Black & White (Grayscale):** সাধারণ সাদা-কালো (অটোমেটিক কালার স্ট্রিপ করে শতভাগ গ্রেস্কেল করা হয়)।
   - **Pure Monochrome:** হাই-কন্ট্রাস্ট ব্ল্যাক অ্যান্ড হোয়াইট (সর্বোচ্চ টোনার সেভিং)।
3. **পেজ সিলেকশন ও রিভার্স নির্বাচন:**
   - যদি শেষ পাতা থেকে প্রথমে প্রিন্ট করতে চান, তবে **🔄 Reverse Order** বক্সে টিক দিন।
   - প্রয়োজনমতো **Odd Pages** অথবা **Even Pages** সিলেক্ট করুন।
4. **প্রিন্ট করুন:**
   - ড্রপডাউন থেকে আপনার প্রিন্টার সিলেক্ট করুন এবং কপি সংখ্যা দিন।
   - **🖨️ Print Now** বাটনে ক্লিক করলেই সরাসরি প্রিন্টারে প্রিন্ট কমান্ড চলে যাবে!

## 🧪 টেস্ট রান করা (Running Tests)

প্রজেক্টের পেজ ফিল্টারিং, রিভার্স লজিক এবং CUPS কমান্ড জেনারেটরের ইউনিট টেস্ট চালাতে:

```bash
python3 -m unittest discover -s tests -v
```
